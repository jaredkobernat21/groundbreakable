# Methodologies

Groundbreakable methodology docs — how research and discovery actually get done, distinct from
`SLADE/DATA_MODEL.md` (what gets stored) and `SLADE/docs/LODE.md` (the pipeline shape).

The first real methodology doc already exists outside this folder, at
`research/small-builder-lead-sourcing-method.md` — a worked, reusable method for sourcing small
builder/developer prospects, distilled from a real KC-metro run. It's left in place rather than
moved here because it's tied to that research folder's own examples; this folder is where new,
SLADE-specific methodology docs get added going forward (e.g. a site-verification method, an
ownership-research method) as they get proven the same way that one was — by doing the work once,
carefully, and writing down what actually worked.

No fabricated methodology docs were added in Phase 1 — this folder starts empty by design.
